General Settings

Operation Mode

Choose how Spambuster handles detected spam.

Learning Mode (Dryrun)

Emails are scanned and flagged, but no automatic actions are taken.

  • Review what the system detects as spam
  • Label emails to improve the model
  • Build confidence before enabling protection

Enforcement Mode (Protection)

Detected spam is automatically handled based on confidence.

  • Above delete threshold: Email is deleted (with backup)
  • Above move threshold: Moved to spam folder
  • Above warn threshold: Warning banner injected
  • Below warn threshold: No action taken
