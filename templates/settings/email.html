Setup Help

Gmail Setup
  1. Enable 2-Factor Authentication on your Google account
  2. Go to App Passwords
  3. Select "Mail" and your device, then generate
  4. Use the 16-character password here (without spaces)

Server: imap.gmail.com | Port: 993

Yahoo Mail Setup
  1. Go to Account Security settings
  2. Generate an App Password
  3. Use that password here

Server: imap.mail.yahoo.com | Port: 993

Outlook/Office 365 Setup
  1. Your regular Microsoft password usually works
  2. If 2FA is enabled, create an App Password in Security settings

Server: outlook.office365.com | Port: 993

Your credentials are encrypted using AES-128-CBC encryption before being stored.
