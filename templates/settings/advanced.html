API Documentation

Spambuster provides a REST API for integration with other systems. All endpoints require authentication.

Endpoint Method Description
/api/stats GET Get statistics
/api/scan POST Trigger a scan
/api/predict POST Predict if text is spam (JSON: {"text": "..."})
/api/mode GET / POST Get or set operation mode
/api/chart-data GET Get spam statistics for charts (query param: days)
/api/explain/<email_id> GET Get explanation for email classification
/api/email/<id>/preview GET Get email content for preview
/api/discord/status GET Get Discord bot status and activity
/api/discord/activity POST Set bot activity (JSON: {"type": "watching", "name": "..."})
/api/discord/start POST Start the Discord bot

Example API Usage

Use cURL or any HTTP client to interact with the API. Sessions are cookie-based.

Get Statistics

curl -b cookies.txt {{ request.url_root }}api/stats

Predict Spam

curl -b cookies.txt -X POST -H "Content-Type: application/json" \
     -d '{"text": "You won a free iPhone!"}' \
     {{ request.url_root }}api/predict

Trigger Manual Scan

curl -b cookies.txt -X POST {{ request.url_root }}api/scan
