Security Standards

Spambusters implements defense-in-depth security across all layers of the application.

Authentication

  • PBKDF2-HMAC-SHA256 password hashing
  • TOTP two-factor authentication (RFC 6238)
  • 12+ char passwords with complexity rules
  • Account lockout after 5 failed attempts
  • Role-based access control (RBAC)

Encryption

  • AES-128-CBC credential encryption
  • HMAC-SHA256 integrity verification
  • Hierarchical key management (Master > User)
  • PBKDF2 key derivation (480K iterations)
  • Automated key rotation support

Web Security

  • CSRF protection on all forms
  • Content-Security-Policy headers
  • X-Frame-Options: DENY (anti-clickjacking)
  • HttpOnly, Secure, SameSite cookies
  • Jinja2 auto-escaping (XSS prevention)

Rate Limiting & Sessions

  • Login rate limiting (5/min)
  • API endpoint rate limiting
  • 30-minute session timeout
  • Session fixation protection
  • HMAC-signed session cookies

Data Protection

  • Parameterized SQL (injection-proof)
  • Multi-tenant data isolation
  • Foreign key constraints
  • Secure cascading user deletion
  • Webhook HMAC authentication

Standards Compliance

  • OWASP Top 10 coverage
  • OWASP 2023 PBKDF2 iteration count
  • RFC 6238 TOTP implementation
  • Constant-time comparison (timing attack safe)
  • Permissions-Policy header restrictions
